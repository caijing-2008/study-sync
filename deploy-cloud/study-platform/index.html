怎么用这个平台

  1. 载入课本：点右上「载入课本PDF」，选你的扫描版 PDF；之后左侧可翻页浏览。
  2. 问题目：点顶部「答疑」标签页直接问（首次在 ⚙ 设置里填你的 API Key，浏览器直连大模型，无需后端）；或回 LearnBuddy 对话说「P127 第5题不会」。讲解为教辅式分步（含正规公式）。
  3. 存入题库：对话回答下方点「＋ 存到我的题库」，该题即进入「题目」列表，可搜索、可标记进度（存在本机浏览器）。
  4. 自动入库：通过 LearnBuddy 对话讲解的题会被写进 data/problems.json，刷新本平台即可看到、可搜索。
  5. 考点：把考卷发给 LearnBuddy，它读卷后给出文字版考点总结（高频/易错/分布），并沉淀到「考点」标签页；也可在「考点」页点「＋ 添加考卷」自己录入。
  6. 定位：顶部搜索框输入「P127 第5题」直接跳转；输入章节/概念也能搜。
  7. 追踪：每题可标记「已学会 / 已掌握 / 加入错题」，进度与连续学习天数自动记录。
  8. 引导模式：在「答疑」里默认开启，连小理会一步步追问、不直接给答案；卡住了说「给我答案」即可要完整解。
  9. 薄弱点：把错题标记为「加入错题」并填它对应的教材定理/定义，会在「薄弱点」标签页聚成你的个人图谱，可一键导出 JSON / CSV。
  10. 截图问：在「答疑」里点 📎 或把截图直接粘贴到输入框，连小理会看图解题（比 OCR 识别更靠谱）。图片只存在本机浏览器。
  11. 答疑转笔记：每条答疑回答下方有「📝 加入笔记」按钮，点一下就把整段回答（含附图）存进「笔记」标签页，自动跳过去，可继续补充老师的教案。
  12. 周报：点顶部「周报」标签页，连小理会跨会话读取你全部答疑、错题归因与进度，自动汇总「本周学了哪几章 / 错题集中在哪些定理 / 进步在哪 / 下周攻哪」，可导出 Markdown。
  13. 上课笔记：点顶部「笔记」标签页，自己记录老师的教案、板书和课堂照片，支持传图 / 粘贴，与题库/答疑数据一起存在本机浏览器。

提示：PDF 仅在本机浏览器打开，不会上传；题目/考点数据存在本地浏览器与 workspace。

对话设置

Key 只存在你本机浏览器，不会上传到任何服务器（网站是纯静态的）。

遇到「截图提问 / P页码 发书页图」时自动改用此模型；留空则仍用上面的模型。需选带视觉能力的模型（如 qwen-vl-max / glm-4v-plus / gpt-4o）。

支持 OpenAI 兼容接口：DeepSeek / OpenAI / 通义千问 / 智谱 / 本地 Ollama 等。若浏览器提示跨域(CORS)失败，可换支持 CORS 的接口或本地代理。

添加书籍

上传的 PDF 会存到你本机浏览器（IndexedDB），刷新不丢、不上传服务器。看完书页图靠实时渲染，不需要额外OCR。

添加考卷

录入到「考点」库（存在本机浏览器）。上传考卷 PDF 后，详情页会以原图展示，并支持针对考卷答疑；也会自动提取原文作为备用。
